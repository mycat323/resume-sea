三步发布你的简历

本地运行转换工具，生成静态站点，推送到 GitHub 即上线

1

转换简历

支持 PDF / Word（.docx）简历，自动解析为统一数据格式（RSUF），可人工校对。

python tools/convert.py 简历.docx --name myresume
2

选择模板

内置 Orbit 经典侧栏模板，8 种配色皮肤一键切换；模板库持续扩充。

--template online-cv --skin blue
3

推送发布

提交推送到 GitHub，GitHub Pages 自动上线，立刻获得独立网址。

git push → mycat323.github.io/resume-sea/myresume

模板基座选型结论

为什么 resume-sea 选择 online-cv 作为第一个模板

✓

sharu725/online-cv —— 已采用

内容全部集中在 _data/data.yml 单一数据源，结构字段化程度最高，与简历解析结果的映射最直接；自带 /print 打印页与前端 PDF 导出；8 种配色皮肤一键切换，天然满足“多模板选择”诉求。

✗

jekyller/PanelCV —— 暂不采用

卡片式动态 vCard 视觉效果强，但内容硬编码在各 HTML 片段中，非数据驱动，程序化生成需要先做一轮模板改造，成本高。

✗

piazzai/cvless —— 规划中

学术极简风、打印自适应、支持博客，适合科研场景；但以 Markdown 驱动、面向手工维护，接入需先补充结构化适配器，列入路线图。
